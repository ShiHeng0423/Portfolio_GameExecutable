Hidden Button

-Keyboard Button L to access to the debugger/cheat mode of the game
	-Enemy type for which type of enemy to spawn instead of random (0 means random)
	-Boss type for which type of boss to spawn immediately (0 means random)
	-Player One Punch for one shot one kill
	-Player Invincible for the ship invincibility
	-Base Invincible for the base not to get damage from enemy and asteroids
	-Credits to add 1000 to buy items in the shop
	-Confirm to apply the effects except the add credits which is auto added auto clicking

        - Key 1 for Balance Body Type  
	- Key 2 for Speed Body Type  
	- Key 3 for Tank Body Type  
	- Key 4 for Damage Body Type  

	- Key 5 for Balance Wing Type  
	- Key 6 for Speed Wing Type  
	- Key 7 for Tank Wing Type  
	- Key 8 for Damage Wing Type  

	- Key H for Balance Engine Type  
	- Key J for Speed Engine Type  
	- Key K for Tank Engine Type  
	- Key L for Damage Engine Type  

	- Key Z for Rifle
	- Key X for Shotgun
	- Key C for Cannon
	- Key V for Machinegun

	- Key F to game over
